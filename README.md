# TerraSight 360

Live website: https://ketakioak-123.github.io/terrasight-360/

`index.html` is the latest self-contained browser prototype. Download and extract `TerraSight-source.zip` for the modular editable source, tests and processing pipeline. Licensed Indian imagery attribution is in ATTRIBUTION.md. Uploaded videos and IndexedDB memory stay in the browser.

Deployment: Settings → Pages → Deploy from a branch → main → / (root).
